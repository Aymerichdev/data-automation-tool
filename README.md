# Data Quality Automation Tool

This project implements a Python-based data processing pipeline designed to clean, validate, and analyze transactional datasets.

## Features

- Duplicate removal
- Null value handling
- Data standardization (country normalization)
- Business rule validation
- Automated metric generation
- Data quality reporting
- Structured logging

## Technologies Used

- Python
- Pandas
- Logging

## Business Metrics Generated

- Total Revenue
- Revenue by Country
- Top 5 Products by Revenue
- Valid Transactions Count
- Data Quality Report

## How to Run

pip install -r requirements.txt
python src/main.py

## Use Case

This tool simulates enterprise data governance processes by applying business validation rules and generating structured insights from raw transactional data.
